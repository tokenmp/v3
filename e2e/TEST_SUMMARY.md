## 发现的问题

### P0：核心安全与明显缺陷

1. **Panel 请求日志失败筛选不一致**
   - 问题：`/panel/requests` 的"失败"筛选使用 `failed`，但实际日志状态为 `error`
   - 影响：失败筛选始终为空
   - 建议：统一使用 `error` 状态值

2. **API Key Secret 显示安全**
   - 问题：需要确保完整 secret 只在创建时显示一次
   - 影响：安全风险
   - 建议：验证关闭 Dialog 后 DOM 不再包含完整 secret

3. **上游凭据安全**
   - 问题：编辑时 API Key 不应回填，留空表示保持旧密钥
   - 影响：安全风险
   - 建议：验证 DOM、网络响应和 toast 均不泄漏完整 secret

4. **认证和 Token 刷新**
   - 问题：需要验证 Access Token 过期后的自动刷新机制
   - 影响：用户体验
   - 建议：添加 Token 刷新的 E2E 测试

### P1：主要业务操作

1. **套餐管理表单验证不足**
   - 问题：负价格、负额度、非整数等边界情况
   - 影响：数据完整性
   - 建议：添加前端校验

2. **Provider 管理编译失败处理**
   - 问题：编译失败时配置不应展示为已发布
   - 影响：用户体验
   - 建议：明确显示编译状态

3. **通知管理 Action 校验**
   - 问题：非法 href、空 label、未知 type 无前端校验
   - 影响：数据质量
   - 建议：添加前端校验

### P2：列表体验

1. **搜索和筛选仅作用于当前页**
   - 问题：搜索和筛选不是全局搜索
   - 影响：用户体验
   - 建议：明确提示或实现全局搜索

2. **分页信息语义不一致**
   - 问题：客户端筛选后总数仍是服务端总数
   - 影响：用户体验
   - 建议：调整分页信息显示

3. **Notice 列表无分页**
   - 问题：公告、版本日志、通知只显示前 20 条
   - 影响：数据完整性
   - 建议：添加分页功能

### P3：可访问性

1. **缺少 label 的输入框**
   - 问题：搜索输入框缺少关联 label
   - 影响：可访问性
   - 建议：添加 `aria-label` 或 `label` 元素

2. **Icon-only 按钮缺少可访问名称**
   - 问题：排序图标按钮等缺少 `aria-label`
   - 影响：可访问性
   - 建议：添加 `aria-label` 属性

3. **Dialog 焦点管理**
   - 问题：需要验证焦点进入 Dialog、Escape 关闭、关闭后焦点返回
   - 影响：可访问性
   - 建议：添加焦点管理测试

4. **状态变化缺少 aria-live**
   - 问题：服务状态轮询等缺少 `aria-live` 属性
   - 影响：可访问性
   - 建议：添加 `aria-live` 属性

## 测试运行指南

### 安装和配置

```bash
# 进入 e2e 目录
cd e2e

# 安装依赖
./run-tests.sh -i

# 或者手动安装
pnpm install
pnpm install:browsers
```

### 运行测试

```bash
# 运行所有测试
./run-tests.sh -a

# 运行特定测试
./run-tests.sh -s tests/admin/users.spec.ts

# 运行带 UI 的测试
./run-tests.sh -u

# 调试模式运行
./run-tests.sh -d

# 查看测试报告
./run-tests.sh -r
```

## 总结

TokenMP v3 的 E2E 测试覆盖了主要的 admin 后台和 panel 用户面板功能，包括：

- ✅ 29 个页面的完整功能测试
- ✅ 响应式设计测试（桌面和移动视图）
- ✅ 错误处理和边界情况测试
- ✅ 用户交互和表单验证测试
- ✅ 搜索、筛选和分页功能测试

测试发现了几个需要改进的问题，主要集中在：
1. 数据一致性（筛选状态值）
2. 安全性（API Key 显示）
3. 表单验证（边界情况）
4. 可访问性（label 和 aria 属性）

建议按照优先级逐步修复这些问题，并持续完善测试覆盖。
